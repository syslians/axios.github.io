**5. 확인된 컬럼으로 데이터 조회**

- `AND 1=0` : 원래 `movies` 조회 결과를 0행으로 만듭니다.

- `UNION ALL SELECT ...` : `cisco`의 행을 추가합니다.

- `#` : 원래 SQL의 남은 부분을 주석 처리합니다.
